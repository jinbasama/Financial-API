## 复核过但判定「不是缺陷」

| 项 | 结论 |
| --- | --- |
| 凭据文件带 BOM 时读不到 Key | **不成立**：JS `trim()` 会剥 U+FEFF。已加测试锁定该行为，防止将来改成不用 trim 时悄悄回归 |
| `apply` 里 `settings.apiKey` 非字符串（如对象） | 已被 `normalizeConfig` 丢弃，退回空串，不会拼进请求头 |
| junction 用 `Remove-Item -Recurse` 删除 | 危险（可能走进目标删真文件），本脚本用 `cmd /c rmdir`。已确认写法安全 |
| 重复 `apply` 会串状态 | 不成立：每个 apply 自己有 `state`，`seen` 只在单次内生效 |
| `readVersion()` 每次 apply 读一次 package.json | 可接受，2 KB 内的一次同步读 |
